# Portfólio de Estudos em Bancos de Dados

Este repositório reúne estudos e projetos relacionais, com foco em modelagem, integridade e SQL. Os esquemas PostgreSQL e SQL Server adicionados ao portfólio contêm somente estrutura, sem linhas de dados.

## Projetos

- [PostgreSQL](postgresql/README.md) — esquema do projeto `data_science`.
- [SQL Server](sql-server/README.md) — esquema derivado do pacote `Banco_Empresa.bacpac`; o pacote original não é publicado.
- [EscolaDB — MySQL](Escola_db/README.md) — modelo escolar, script consolidado, diagrama ER e documentação técnica.
- [Comercio_db — MySQL](Comercio_db/README.md) — projeto MySQL mantido separado.

Os registros de exemplo dos anexos PostgreSQL e SQL Server foram removidos das versões preparadas para publicação por conterem informações pessoais aparentes. O BACPAC original não está no repositório. O EscolaDB possui dados de exemplo e um aviso de privacidade próprios; consulte seu README e revise os registros antes de qualquer publicação.

## Organização

Os materiais estão separados por tecnologia e por projeto. Os esquemas foram revisados preservando as regras existentes; os pontos que dependem de regras de negócio estão registrados nos READMEs correspondentes.
